# Raw Data

The raw data are from the National Highway Traffic Safety Administration (NHTSA) Fatality Analysis Reporting System (FARS).

FARS National CSV files were downloaded for 2020–2024. (The original raw files are retained locally and are not uploaded to this repository due to file size.)

## Source 1. 

National Highway Traffic Safety Administration (NHTSA)
- Download Raw Data From FTP Site
- Search "FARS"
- Select year "2024"
- Select "National"
- Download "FARS2024NationalCSV.zip"

Source Link:
https://www.nhtsa.gov/research-data/fatality-analysis-reporting-system-fars

## Source 2.

U.C. Census Bureau
- 2024 State Population
- NST-EST2024-POP.xlsx

Source Link: https://www.census.gov/newsroom/press-kits/2024/national-state-population-estimates.html
